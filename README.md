# 📊 Sales Performance Dashboard — Microsoft Excel

An interactive Sales Performance Dashboard developed in Microsoft Excel to analyze revenue, profitability, regional performance, product performance, salesperson performance, and discount impact using a FY2025 sales dataset.

---

## 📌 Project Overview

The objective of this project was to transform raw sales transaction data into an interactive business dashboard that enables management to monitor key performance indicators and identify important sales and profitability trends.

The project follows an end-to-end analytical workflow:

Raw Data → Data Preparation → KPI Development → Pivot Analysis → Visualization → Interactive Dashboard → Business Insights

---

## 🎯 Business Objectives

The dashboard was designed to answer the following business questions:

- What is the total sales revenue?
- What is the total profit?
- What is the overall profit margin?
- How many orders were generated?
- How many units were sold?
- What is the average order value?
- How are sales trending over time?
- Which region generates the highest sales and profit?
- Which product category contributes the most revenue?
- Which products generate the highest sales?
- Which salespeople perform best?
- How does profitability vary by discount level?
- How many transactions are loss-making?
- Which areas require further business investigation?

---

## 📂 Dataset

The project uses a 500-row FY2025 sales transaction dataset.

### Key fields include:

- Order ID
- Order Date
- Customer Name
- Region
- State
- Category
- Sub-Category
- Product
- Quantity
- Sales
- Discount
- Profit
- Salesperson

Additional calculated fields were created for analysis.

---

## 🧮 Calculated Fields

The following analytical fields were created:

### Year

Extracted from Order Date.

### Month

Used for monthly sales trend analysis.
